## Answer Q3-05

**16(h): $4,199** (mean headline penalty over 2,502 cases with a headline above $0)
**20(a)(2): $3,787** (mean headline penalty over 1,888 cases with a headline above $0)

Both figures come from the pre-computed tables in `reference/tables/`, not the raw case data. Zero-headline cases add nothing to the sum, so each mean is the table's sum divided by the count of positive-headline cases (total n minus zero count).

- **16(h):** sum $10,505,900; n = 3,941; zero = 1,439; positive n = 2,502. Mean = 10,505,900 / 2,502 = 4,199.0. Table 03 S1 gives the base section and S4 gives its cites (16(h), (expire), (other), (out), (prior)), which sum to the same totals.
- **20(a)(2):** sum $7,150,700; n = 2,284; zero = 396; positive n = 1,888. Mean = 7,150,700 / 1,888 = 3,787.4. Table 03 S4 splits this into 20(a)(2) (n = 2,283) and 20(a)(2)(expire) (n = 1), which together match the S1 totals.
